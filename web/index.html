Status and diagnostics


Explore the compiler with your own code
Edit the Source tab and choose Compile & run. The actual Crystal compiler and LLVM run in your browser; LLD links the WASM program before execution.
  1. Choose initial code in Source, or write your own. Example trace opens a saved recording for the selected example.
  2. Choose Compile & run, Compile → IR, or Parse only.
  3. Select an event in History. Inspect its AST in the center, its node at the upper right, and the visitor role and operation below.
  4. Open or save traces in History. Set stdin and arguments, or rerun a compiled program, in Output.
Layout and language
Drag the column dividers or the horizontal inspector divider. Focus a divider and use arrow keys, or Home to reset it. Escape exits maximized view. English is the default; an explicit JA / EN preference is saved.
Runtime
The first run loads the compiler, LLVM, LLD and standard library. A static HTTP server or GitHub Pages is enough. Source code is not uploaded. The browser must support WebAssembly exception handling.
Programs target WASI. OS processes, sockets, native shards and host files are unavailable. Program memory is limited to 256 MiB and execution to 10 seconds.
Reading the trace
ASTs are snapshots taken after stages, expansions and call resolution. Type dependencies and the visitor stack reflect the selected event. IR insertion positions include instructions emitted by children. Recorded traces are historical measurements; Syntax uses a separate lightweight engine. Code, compiler diagnostics and internal identifiers remain unchanged.
